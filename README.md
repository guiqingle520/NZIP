# NZIP 收费版开发分支

当前 `paid-version` 分支开发原生收费版 0.7.4，首版支持签名设备授权、首次联网激活、永久离线使用、3 个当前登记设备名额、自助解绑换机和购买邮箱设备管理。具体交付与验证见 [收费版说明](docs/commercial/implementation-v0.7.0.md)，部署见 [授权服务](server/README.md)。正式域名、邮件服务和正式密钥尚需发行方配置，当前安装包为测试构建。

0.6.5 / 0.7.4 优化目录流式解析、关闭后的目录索引释放、ZIP 元数据合并和进度刷新。新增十万条目反复浏览 / 关闭及 256 MiB 实际压缩解压回归。免费安装包为 `dist/NZIP-0.6.5-Setup-x64.msi`，收费测试安装包为 `dist/NZIPPaidPreview-0.7.4-Setup-x64.msi`；方法、实测内存和边界见 [验证记录](docs/commercial/validation-v0.7.4.md)。

0.6.4 / 0.7.3 按 Bandizip 官方说明补齐包内文件编辑流程：通过 Windows 关联程序打开；保存并关闭编辑器后，ZIP / ZIPX 内容变化会询问是否回写；退出时清理正常副本，回写失败保留原包和可找回的编辑副本。免费安装包为 `dist/NZIP-0.6.4-Setup-x64.msi`，收费测试安装包为 `dist/NZIPPaidPreview-0.7.3-Setup-x64.msi`；见 [验证记录](docs/commercial/validation-v0.7.3.md)。

0.6.3 / 0.7.2 修复深层目录解压时的长路径错误：文件操作显式使用 Windows 扩展路径，并补齐 .NET 4.8 启动配置，无需修改系统全局长路径策略。双击深层文件时，将独立副本放到较短的临时路径交给本地程序。免费安装包为 `dist/NZIP-0.6.3-Setup-x64.msi`，收费测试安装包为 `dist/NZIPPaidPreview-0.7.2-Setup-x64.msi`；见 [验证记录](docs/commercial/validation-v0.7.2.md)。

0.7.1 修复目录切换、搜索和关闭压缩包时虚拟列表数据与 Windows 行号不同步造成的索引越界。安装包为 `dist/NZIPPaidPreview-0.7.1-Setup-x64.msi`；编译和打包核验通过，新增界面回归被本机应用控制拦截，尚未运行完成，详见 [修复验证记录](docs/commercial/validation-v0.7.1.md)。

既有代码继续适用原 MIT 许可，新增商业授权实现的范围见 [LICENSES.md](LICENSES.md)。

## 免费版 0.6.4

无广告、无需登录的 Windows 本地压缩解压工具。主界面已改为 **C# / .NET Framework 4.8 原生 Windows Forms**，无需 WebView2，不包含 Electron、Node.js 或浏览器内核。

0.6.2 修复任务窗口“打开结果位置”无响应：默认选中有输出的完成任务，选择在刷新后保持；无输出时按钮禁用，输出被删除时明确提示。解压任务打开输出目录，压缩任务在资源管理器中选中生成的压缩包。

0.6.1 将目录浏览与内容查看明确区分：双击文件夹进入目录，双击文件提取临时副本，用本地程序打开；文本和源代码交给记事本。保留可选的内置文本 / 图片内容预览。

0.6.0 将创建格式扩展为 ZIP、7Z、TAR、WIM、GZ、BZ2、XZ、TAR.GZ、TAR.BZ2、TAR.XZ。复合 TAR 支持直接浏览、预览和一步解压；打开、批量解压、拖放、Windows 打开方式和右键菜单统一使用 69 个扩展名入口。保留 0.5.1 工具栏重绘修复。

## 安装与运行

安装包：dist/NZIP-0.6.4-Setup-x64.msi。检测当前用户旧版并默认沿用原安装目录；首次默认安装到 LocalAppData\Programs\NZIP。可选打开方式、传统右键菜单和快捷方式。

保留 0.4.1 的安装维护提权声明和日志记录。数据盘安装维护请从管理员终端启动 MSI，日常使用不需要提权。安装仍属于当前用户，不更改系统安全策略或共享 Config.Msi 权限。未签名 EXE 安装入口被本机应用控制阻止，交付使用系统 MSI 服务。

便携版：完整解压 dist/NZIP-0.6.4-win-x64.zip，运行 NZIP.exe，保留 NZIP.exe.config、7zip 目录及许可文件。要求 Windows 10/11 x64、.NET Framework 4.8，无需 WebView2。

## 截图中的操作

- 文件：打开、最近文件、新建、关闭、另存为、回收站 / 永久删除原包、定位、测试、扫描、解压、新窗口、管理员窗口、退出。
- 编辑：包内重命名、添加、删除、ZIP 整包注释、复制真实文件到剪贴板、从资源管理器粘贴入当前目录、复制完整路径、全选、反选。
- 查找与视图：路径 / 文件名搜索、详细 / 图标视图、目录树、刷新、预览、属性、任务记录。
- 查看工具栏：截图中的十个可选字段，包括大小、类型、时间、方法、加密、CRC、属性、备注和附加信息；格式没有的元数据留空。
- 代码页：截图中的全部十五个选项及自动检测，同一编码用于浏览、测试、预览、复制和解压；识别 ZIP Unicode 路径扩展。旧 ZIP 自动检测是启发式结果，可手动覆盖。
- 设置：常规、关联、上下文菜单、解压、压缩、查看、安全、高级、语言九页。支持导入导出、临时目录、附加扩展名、历史、回收站、长路径、打开文件锁、展开、进度、首页、标题路径、空间检查、文件大小预分配、压缩级别 / 线程、文本编码、浅色 / 深色 / 系统主题。界面语言仅简体中文。
- 工具：普通 ZIP 修复、本地字典 / 字符组合密码恢复、批量解压。任务支持队列、进度、取消和结果定位。

创建十种格式。ZIP / 7Z 支持 AES-256 和分卷，7Z 可加密文件名。GZ / BZ2 / XZ 只压缩单个文件，多个文件或文件夹选择 TAR.GZ / TAR.BZ2 / TAR.XZ；其他格式不支持密码或分卷，TAR 仅打包。

解压覆盖 RAR / RAR5、ZIP / ZIPX、7Z、TAR 及压缩 TAR、GZ / BZ2 / XZ / ZST / LZMA / Z、CAB、WIM / ESD / SWM、ARJ、LZH / LHA、CPIO、DEB / RPM、DMG / XAR、ISO / UDF 和部分磁盘镜像；JAR / WAR / EAR、APK、EPUB、CBZ、APPX / MSIX 等按实际容器读取。扩展名数量不是独立格式数量，具体编码 / 镜像兼容性以 [7-Zip 官方支持范围](https://www.7-zip.org/) 为准，含链接或不安全路径仍会拒绝。RAR、ZST、LZMA 仅解压，不能创建。

目录树 / 文件列表浏览、普通压缩 / 解压没有人为的文件字节数上限，受格式、磁盘空间和内存等限制；目录信息输出保护上限为 64 Mi 字符，因此极多条目可能超限。

双击文件只解压该文件到临时目录的 NZIP-opened 子目录，再通过 Windows 文件关联打开；程序 / 安装包 / 快捷方式需先手动解压。此路径没有内置预览的 10 MB 限制，实际能力取决于本地程序。ZIP / ZIPX 文件保存并关闭编辑器后，检测内容变化并询问是否回写原包；选择“否”保留原包。正常副本在退出 NZIP 时清理，回写失败的副本保留并显示找回路径。复用进程或不提供退出状态的编辑器可能无法自动检测关闭；在编辑器之前退出 NZIP 不能继续自动回写。其他格式不提供编辑回写。

可选的“内置内容预览”不执行内容，上限 10 MB，文本显示上限 200,000 字符，图片限 4,000 万像素。压缩 TAR 需要临时磁盘空间展开 TAR；BZ2 等格式可能不记录原始大小，显示“未知”，空间预检查不能准确估计这些文件，失败仍会清理暂存输出。

## 实现边界

这仍不是完整 Bandizip 等价版，详见 FEATURES.md。

- ZIP 修复限普通 Store / Deflate，输入最多 2 GB，解压总计 512 MB / 10,000 项 / 单项 64 MB。CRC 验证后生成新包，保留原包并报告跳过内容；不支持加密、ZIP64、分卷、其他格式或已丢失的数据。
- 密码恢复限 ZIP / 7Z，使用 UTF-8 字典或指定字符集 / 长度；最多 100 万候选、30 分钟，可取消，不保证成功。仅用于有权访问的文件。密码不写入配置、历史或日志，界面取走结果后从任务记录移除。
- 包内修改限默认代码页下未加密 ZIP / 7Z，整包注释编辑限 ZIP；UTF-8 注释可能被旧软件按本地编码显示。
- 解压使用新目录，不覆盖合并。无 RAR / ZST 创建、SFX、ALZ / EGG、密码管理器或自动更新。
- 可选的内置内容预览支持文本、PNG / JPEG / GIF / BMP / ICO / TIFF；不支持 WebP、Office、PDF、SVG、视频。
- Windows 11 右键入口在“显示更多选项”。打开方式注册不会强制更改默认应用。
- AMSI 需要可用杀毒引擎；本机只验证引擎不可用时的明确失败，未验证有效引擎的威胁检出。
- 长路径还取决于系统和文件系统支持。预分配先设置临时输出文件大小，7-Zip 随后覆盖写入，不保证物理连续分配。写入中文件可能得到不一致快照。
- 安全路径检查和失败 / 取消后的回滚始终开启。开发版尚未代码签名。

## 构建与验证

Windows 自带 .NET Framework 编译器即可构建。Node.js 只用于开发脚本：

    npm run build
    npm run build:installer
    npm test
    npm run test:ui
    npm run test:package
    npm run test:shell
    npm run benchmark:normal

原生界面测试会显示独立测试窗口，操作真实控件和临时压缩包，使用隔离配置，恢复剪贴板，不改用户右键注册。工具栏检查直接采集测试窗口屏幕区域，其他截图使用控件位图；截图在 test-results/native-desktop。引擎测试涵盖往返、AES、分卷、事务、安全路径、取消、注释、修复、密码恢复和编码。

安装回归：npm run test:installer-location。请求系统管理员确认，以独立产品 / 组件 / 注册表 / 目录测试中文路径、修复、升级、卸载和用户文件保留，不替换日常 NZIP；拒绝包含错误 1926 或 Return value 3 的日志。仅检查返回码不算通过。WiX ICE 静态验证受系统策略限制，实际提权测试须单独完成并检查日志。

源码位于 native：DesktopWindow / DesktopDialogs / SettingsWindow 为原生界面；ArchiveTools 为 ZIP 元数据、注释、修复与密码恢复；其他模块负责队列、引擎、扫描和 Windows 集成。src/ui 等旧界面仅作历史参考，不包含在当前发布包。

许可与引擎源码入口见 THIRD_PARTY_NOTICES.md；启动测量与限制见 PERFORMANCE.md。
