# 0.7.0 / 0.8.0 功能扩展交付与回归

2026-10-25，Windows x64，`paid-version`。免费版 0.7.0，收费测试版 0.8.0。收费版沿用现有测试授权公钥和有效隔离证书；没有覆盖或删除用户授权缓存，没有改变永久离线与自助解绑方案。

## 本次交付

| 功能 | 实现与边界 |
| --- | --- |
| 覆盖合并解压 | 解压对话框选择覆盖、跳过、自动重命名、仅覆盖较旧文件或拒绝已有目录。先在同盘暂存、完整解压并验证，再提交；保留未涉及的文件。文件 / 目录类型冲突拒绝，提交失败回滚；回滚也失败时按原相对目录保留备份并报告恢复路径。 |
| 文件拖出 | 从包内文件列表拖出选中项；准备独立副本，提供真实 CF_HDROP 与 Copy 效果，不删除包内文件。公开 COM 异步复制接口，目标调用 Start / End 时保留源；操作结束后释放数据对象，退出时清理普通副本，未结束的异步副本保留。大量内容准备期间须保持拖动。 |
| Windows 11 一级右键 | 原生 C++ IExplorerCommand、四个子项、多文件压缩参数、独立产品 CLSID、应用身份 manifest、MSIX、签名与注册脚本已实现。用户没有发行证书，明确选择待签名交付：设置页显示原因并禁用启用按钮，实际一级菜单尚未安装。传统右键保持可用。 |
| 自动更新 | 每日后台检查公开 GitHub Release，可关闭；按产品和版本校验 RSA-3072 签名清单、指定仓库 HTTPS 地址、长度、SHA-256；用户下载并确认安装，安装前再次校验。未发布首个 Release，未执行真实更新安装。 |
| 密码管理器 | Windows CurrentUser DPAPI 加密名称和密码，最多 200 项；保存、删除、在压缩 / 解压中选择。无明文导出、云同步或自动试密码。没有新增主密码；依赖 Windows 账户安全与密钥。 |
| SFX | 已有 7Z 转换为独立 Windows EXE，内置压缩引擎，无需安装 NZIP；只解压到新目录，不自动运行包内内容。模块不含收费激活实现，内嵌 MIT / 7-Zip 许可，可用 `--licenses` 查看。需要临时磁盘空间。 |
| 多语言 | 简体中文、繁体中文、英语，保存后重启；412 条英语界面文案，繁体使用 Windows 字符转换及常用术语。文件名、路径、内容和密码按原样保留；部分引擎 / 系统诊断仍保留原始语言。 |

新增专项实际验证：

- 已有文件覆盖 / 跳过 / 重命名，较旧 / 较新时间戳分支，未涉及文件保留、预分配；用真实 FileShare.Read 文件锁制造提交失败，原文件恢复且备份目录清理。
- 真实提取中文命名的选中文件，核对 CF_HDROP、Copy、COM QueryInterface 和异步复制 Start / End 状态；复制结束前保留文件并禁止清理。**没有自动化操作客户桌面的 Explorer 拖放**，未声称覆盖所有目标程序的异步协议实现。
- 实际 DPAPI 保存、重新读取、确认磁盘无明文、删除后再打开为空。没有读取真实密码库；没有创建其他 Windows 账户来测试跨账户行为。
- 每轮产生临时 RSA-3072 测试密钥，真实签名 / 验签，拒绝坏签名、产品不符、回放 / 降级；隔离 HTTP 处理器驱动完整下载逻辑，核对字节和 SHA-256，拒绝篡改内容及陌生 HTTPS 重定向，清理失败下载。**测试不需要或使用发行私钥，也不启动 MSI。**
- 真实创建 7Z，生成 EXE，启动独立 SFX 进程，检查中文文件内容一致；不依赖主程序目录的引擎路径。
- 三个语言配置实际启动窗口，检查菜单和中文归档 / 条目名称原样保留；原生英语和繁体确认按钮及对话框截图。首轮繁体测试发现 LCMapStringEx 未要求 NUL 终止，已修复；最终各轮通过。

原有全套保留多格式、AES、分卷、长路径、取消、安全路径、事务修改、编辑回写、注释、修复、密码恢复和界面结果按钮等回归。已有本机预览授权缓存存在，未执行要求先删除该缓存的未激活整包脚本；脚本已补上 SFX 门禁检查。没有将源码检查冒充未激活运行验证。

AMSI 本机提供者不可用，验证的是明确失败反馈，不代表恶意内容检出。首轮 WiX 链接因 System64Folder 目录引用缺失失败，已补齐，最终两版 MSI 链接成功。WiX ICE 仍受系统策略限制（LGHT1105）；**本次未实际安装、升级、卸载或注册待签名 MSIX**。未修改信任证书或系统应用控制。

## GitHub 与更新发布状态

按用户明确授权，`guiqingle520/NZIP` 已改为公开；连接器复核 `visibility=public`。公开前遍历全部六个已有提交、205 个唯一文件版本，未发现私钥头、GitHub Token 或常见访问密钥模式；这不是对任意秘密形式的绝对保证。浏览器访问未获准后，通过已有 Git 凭据直接调用同一仓库的 GitHub API 完成，凭据未写入日志、源码或包。

本地已生成两个当前 MSI 对应的更新签名清单：`dist/NZIP-update.json`、`dist/NZIPPaidPreview-update.json`。签名工具先只读核对 MSI 的 ProductName / ProductVersion，拒绝错产品或版本，再核对发行私钥与编译公钥一致。实际错版本签名测试确认拒绝且已有清单保持不变。发行私钥仅保存在忽略的 `.cache/update-signing/private.pem`，应在正式发行前安全备份；安装包不含私钥。

没有创建或公开 GitHub Release，因此没有声称客户已完成在线下载更新或真实升级。发布步骤、证书配置与复现方法见 [更新与签名发布](../RELEASING.md)。收费包仍为 Preview，正式授权服务配置不在此次任务内。
