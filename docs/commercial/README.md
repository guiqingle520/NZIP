# NZIP 商业版设计文档

当前依据是 [设计 v1.2](design-v1.2.md) 和 [补充评审 v2](design-review-v2.md)。用户已经确认允许自动解绑释放名额，接受历史永久离线凭证可能继续使用的风险。默认 3 个名额计数服务器当前登记，不设累计发证上限。

历史材料保留用于追溯：

- [初版 v1.0](design-v1.md)：最初方案。
- [评审 v1](design-review-v1.md)：最初风险分析，其中 R01 的累计发证和常规人工换机措施已被新决策替代。
- [设计 v1.1](design-v1.1.md)：历史修订快照，不再作为现行换机规则。

首版实现已开始落地，使用方式、部署与验证见 [开发交付说明](implementation-v0.7.0.md) 和 [授权服务说明](../../server/README.md)。正式发行前需配置真实 HTTPS 授权域名、邮件服务和正式签名密钥。
