NZIP 0.6.4 — Windows x64 无广告压缩工具

本版采用原生 C# / Windows Forms，无需 WebView2 或浏览器内核。
0.5.1 修复工具栏黑底、图标重叠和文字残影。
需要 Windows 10/11 x64、.NET Framework 4.8，已包含 7-Zip 引擎。

安装 MSI 自动检测并默认沿用原安装目录；数据盘安装维护请从
管理员终端启动 MSI。程序日常运行无需提权，不更改默认压缩软件。
便携版请完整解压 ZIP，保留 7zip 目录及所有许可文件。

截图菜单：文件、编辑、查找、选项、视图、工具、帮助。
“查看”工具栏勾选十种列表字段；“代码页”支持十五种选项与自动检测。
支持另存为、回收站 / 永久删除原包、定位、新窗口与管理员窗口。
编辑支持重命名、添加、删除、ZIP 整包注释、复制真实文件、粘贴入包。
双击文件夹浏览目录层级和文件列表，不受内置内容预览的 10 MB 限制。
双击文件按需解压一个临时副本，通过 Windows 文件关联程序打开；
程序 / 安装包 / 快捷方式需手动解压。
编辑 ZIP / ZIPX 内的文件，保存并关闭编辑器后，NZIP 检测内容变化，
询问是否将修改写回原压缩包；选择“否”不改变原包。
回写先验证内容和压缩包，失败时保留原包及编辑副本，并显示找回位置。
副本位于临时目录的 NZIP-opened 文件夹，正常副本在退出 NZIP 时清理。
回写失败的副本保留供找回；退出前仍在编辑的文件无法继续自动回写。
部分复用进程或不提供退出状态的编辑器无法自动检测关闭。
本地打开没有内置预览大小上限，受磁盘空间和对应程序能力限制。
可选的内置内容预览位于“视图”菜单：限 10 MB / 200,000 字符，
不支持 WebP、Office、PDF、SVG、视频；图片限 4,000 万像素。
普通压缩 / 解压无固定字节上限；目录信息输出限 64 Mi 字符，
极多条目的列表可能超限；大文件处理仍取决于格式、磁盘、内存。

设置含九类，支持导入导出、历史、临时目录、回收站、长路径、
打开文件锁、标题路径、压缩参数、文本编码、浅色 / 深色 / 系统主题。
旧 preferences.json 和历史保留，新增界面设置存放于 desktop.json。

创建 ZIP / 7Z / TAR / WIM / GZ / BZ2 / XZ / TAR.GZ / TAR.BZ2 / TAR.XZ。
ZIP / 7Z 支持 AES 与分卷，7Z 可加密文件名；其余格式不支持密码或分卷。
GZ / BZ2 / XZ 只压缩单个文件，目录和多个文件请选择复合 TAR 格式。
压缩 TAR 支持直接浏览、预览、一步解压，需要临时磁盘空间展开 TAR。
打开、拖入、批量解压和 Windows 注册统一识别 69 个扩展名入口。
解压包括 RAR / RAR5、ZIPX、ZST、LZMA、CAB、WIM / ESD、JAR / APK、
EPUB、DEB / RPM、CPIO、DMG、ISO / UDF 和部分磁盘镜像，具体兼容性
以内置 7-Zip 引擎为准。RAR / ZST / LZMA 仅支持解压，不支持创建。
某些流格式未记录原始大小，会显示“未知”，空间预检查无法准确估计。
支持任务队列、批量解压。任务窗口默认选中有输出的完成任务。
“打开结果位置”：解压任务打开目录，压缩任务定位生成的压缩包；
未完成或无输出时禁用，输出被删除时显示错误。刷新保留选中任务。
修改限默认代码页下未加密 ZIP / 7Z，整包注释编辑限 ZIP。
解压使用新目录，不覆盖原目录；失败或取消始终清理未提交结果。
Windows 11 右键入口位于“显示更多选项”，打开方式可选择 NZIP。

ZIP 修复：恢复完整 Store / Deflate 条目，CRC 校验后生成新包，保留原包。
输入最多 2 GB，解压总计 512 MB、10,000 项、单项 64 MB。
不支持加密、ZIP64、分卷或其他格式修复，跳过内容会明确报告。
密码恢复：ZIP / 7Z 本地字典或字符集枚举，最多 100 万候选 / 30 分钟，
可取消，不保证成功；仅用于有权访问的文件。密码不写入配置或历史。
扫描需可用的 Windows AMSI 引擎，不可用时明确失败。

Ctrl+O 打开，Ctrl+N 新建，F4 关闭包，Ctrl+W 退出，Ctrl+T 测试，
Ctrl+I 扫描，Ctrl+E 解压，Ctrl+F 查找，F2 更名，Ins 添加，Del 删包内项，
Ctrl+Del 删除原包，Ctrl+Shift+Del 永久删除原包，Ctrl+C 复制真实文件，
Ctrl+V 粘贴，Ctrl+Shift+M ZIP 注释，F5 刷新，Alt+上 返回上一级，
Ctrl+Shift+N 新窗口，Ctrl+Alt+N 管理员窗口，F12 设置。

无广告、无需登录、不含遥测或自动下载。本地开发版尚未签名。
仍非完整 Bandizip 等价版：无覆盖合并、SFX、ALZ / EGG、密码管理器、
拖出文件、自动更新或完整多语言界面。
中文加密密码请选择 7Z。卸载保留配置、历史和额外用户文件。
